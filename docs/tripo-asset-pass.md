## 接入方式

`tools/assets/import_static_model.py` 离线转换 GLB / OBJ，保留节点变换、UV、法线、
基础色图像与材质因子，输出分部件 OBJ、manifest 和来源哈希。转换不调用外部服务。
压缩、动画、骨骼和透明材质不属于当前静态合同；详见 `tools/assets/README.md`。

场景 JSON 的模型实例增加可选 `texture` 字段；`imported_static` 材质使用模型本身
的 UV。既有程序材质保持原分支。编辑器可编辑模型贴图路径并正确另存、重开，
编辑器预览仍以几何为主，贴图效果在游戏中验收。

步枪通过 `res/config/weapon_presentation.json` 加载，原模型的 +Z 枪口在离线导入时
旋转为 −Z；实际长度归一为0.85米。左右握持和视觉枪口按实际网格拟合，保留既有
后坐、摆动、滑铲和射击规则。模型或贴图缺失时自动使用原程序武器。

## 美术审阅与差异

详细提示词约束造型、氛围和可读性，不要求精细写实。五类模型优先大轮廓、粗壮
结构、简洁色块，适配320×200渲染。

生成结果不保证逐项服从提示词。飞船原始模型破碎感不足，按局部X±4米把真实网格
划分为三块，保留全部原三角面与UV，错位、倾斜后形成可见断缺。骨架原含可辨识
的人类头骨与双足，场景版只保留局部Y≥8且Z≤8的完整三角面，留下肋骨／脊柱残段。
原始下载及原始导入包完整保留；对应资产目录下的派生脚本可重建处理结果。

Crystal新增10个装饰实例：北侧三块船体、东侧一组骨架残段、三处不可达墙冠水晶、
三处最高4.5厘米的浅层地表裂片。完整厚度碎石模型保留供编辑器复用，本轮没有把
大块可穿越石头放到通路上。新增场景72648三角形、10次绘制；原23个模型和碰撞、
85个导航点／171条连接／41个巡路点保持不变。正式地图版本为
`crystal-combat-world-tripo-v1`。

摆放、变换后边界和哈希见 `artifacts/acceptance/tripo-art/actual/placement-report.json`；
独立环境实景图位于同目录的 `final/`。这些相机预览不能代替整局性能或人工试玩。

步枪原始5511三角形，双面材质转换后为11022运行三角形。飞船原始11430、转换后
22860；ATLAS批准其超过原20000运行面数防护线，以保留开放船壳的双面表面，
最终是否可接受仍以实际性能检查为依据。
