# Crystal 巨型模型墙体（2026-10-17）

状态：已实现，正式地图功能验收通过。用户以游戏截图中的白色巨大骨质结构澄清意图：模型应当成为地图墙面
和空间结构的一部分，具有压迫性的巨大尺度。此要求取代上一轮四处低矮模型掩体的摆放。

## 视觉与空间目标

- 船壳：破裂舷侧/甲板残段形成可接近的金属墙面与转角，玩家在巨大残骸旁战斗。
- 骨骸：巨大肋骨/脊柱形成骨墙或拱形边界，明显骨缝保持真实开口。
- 水晶：大块晶体侵入建筑墙面，形成高大的晶壁和不规则轮廓。

以玩家眼高实景验收，优先体块、剪影、接地和空间尺度。建议高度8–16米、跨度12–24米，
尺寸随碰撞/布局调整。模型应实际成为可进入区域的边界或遮蔽物，不能只放到既有墙外。
局部旧墙可以替换或融合，保留连续环路、坡道、桥下空间和出生/裂隙安全；不引入谜题。

复用已生成的真实资源，原始资产保持。巨型代理按最终世界尺度制作，不能直接放大
小掩体代理的近似误差。明确区分大块实体与骨缝，不用整件包围盒封闭明显开口。
