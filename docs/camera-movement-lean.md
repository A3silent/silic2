# 摄像机侧移倾斜（2026-10-31）

已接入左右侧移轻微倾斜与急停惯性回摆。依据角色碰撞解析后的feet位移计算镜头相对
水平速度，5m/s达到约±3°，使用解析二阶欠阻尼弹簧平滑进入/回正。停止侧移会出现
小幅反向回摆，无新增随机抖动；纯前后移动不产生左右倾斜。

倾斜仅进入Camera视图矩阵的up方向，逻辑front/right/up保持；鼠标瞄准、中心射线、
移动与音频方向不受roll改变。第一人称武器与HUD仍在各自屏幕空间绘制。没有改射击/
移动参数，保留用户已有的子弹速度195。暂停冻结，恢复重采样位置，重开清零；异常
位移和长时间间隔重置，避免瞬移造成倾斜冲击。

## 调参

实际入口是 `include/engine/game_config.h` 的 `CameraConfig` 默认字段，修改后重新构建：

| 参数 | 默认 | 含义 |
| --- | ---: | --- |
| leanMaxDegrees | 3 | 稳态倾角；设0关闭，瞬态允许少量超调 |
| leanReferenceSpeed | 5 | 达到稳态倾角的横向速度 |
| leanFrequency | 18 | 弹簧自然角频率rad/s，越大反应越快 |
| leanDamping | 0.55 | 阻尼比，控制回摆 |

GameConfig现有JSON读写API已保存这四个字段；当前应用没有自动加载通用config.json，
因此不提供“编辑JSON即可生效”或热更新承诺。
