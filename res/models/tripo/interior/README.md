# Crystal 内部掩体（本地资源）

本轮复用已经生成的真实 Tripo 网格，没有调用 API 或额外消耗额度。外侧三段飞船、巨大遗骸、水晶、浅碎石和步枪保持原样。内部添加四处可碰撞掩体：旧南侧掩体31替换为侧躺船体碎片，旧东侧掩体32替换为去头腿的肋骨残段；北侧(-9,-9)和南侧(9,23)各放一簇小水晶。

## 可复现离线构建

在项目根目录执行。Python依赖只安装到独立工具环境，不修改系统Python或游戏运行时依赖：

```sh
python3 -m venv artifacts/acceptance/tripo-interior/mesh-tools
artifacts/acceptance/tripo-interior/mesh-tools/bin/python -m pip install numpy==2.5.4 scipy==1.18.1
artifacts/acceptance/tripo-interior/mesh-tools/bin/python res/models/tripo/interior/generate.py
```

`generate.py`读取上一轮真实派生船体`derelict_ship/parts/wreck-0.obj`、真实去头腿骨架`alien_skeleton/parts/torso-derived.obj`、真实`mineral_cluster/parts/part-000.obj`。保留原UV，旋转船体90度后**等比**缩放，重设底部原点；船/骨高1.2m，晶高1.6m，不非均匀压扁。尺寸由实际网格确定。每包的`proxy-report.json`记录源文件SHA256、变换、边界、生成依赖版本、生成OBJ哈希及每壳误差。

极小/近共面孤立组件只在同时移除视觉和碰撞的情况下剔除；其余视觉仍是实际生成的三角面。碰撞按焊接后的源连通片划分，再沿三角面中心最长轴递归分段，使用固定48方向极值点构造局部闭合凸壳。每壳检测边恰有两邻面，并将法线统一向外。没有整件骨架包围盒、没有封满整个胸腔。它是保留主要实体和明显孔洞的离线近似，不是精确物理表面；各分壳可能相交，当前功能探针覆盖实际行走、滑铲、射线、敌弹和敌人绕行。

| 包 | 视觉面 | 代理面 | 闭壳数 | 采样最大表面偏差 | 顶点超出代理支持平面最大值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ship_low | 7268 | 3330 | 213 | 0.209m | 0.039m |
| ribs_low | 7062 | 3852 | 246 | 0.098m | 0.032m |
| crystal_low | 8402 | 3910 | 361 | 0.219m | 0.028m |

表面偏差按凸壳三角形中心及边中点到对应源面最近距离测量，**不是全表面Hausdorff上界**。0.045m是尝试分段阈值；达到最小片段/递归限制或分割后无体积时保留父壳，所以部分局部超过阈值。不能把该阈值写成误差承诺。

## 地图与功能验收

四实例共享视觉/代理局部坐标与同一TRS。31位于(0,0,12)、Y旋转20度；32位于(23,0,-9)、Y旋转-25度；4400位于(-9,0,-9)、Y旋转15度；4401位于(9,0,23)、Y旋转70度。船色因子(2.0,2.15,2.3)只提高暗色贴图局部反射明度，不发光；骨/晶保持克制。导航保留85节点，移除被新水晶阻断的四条双向链接9–15、10–14、33–40、34–40，其余167链接保留，完整路径仍连通。出生、裂隙、巡逻点、坡道和桥保持不变。

功能探针由VECTOR维护：

```sh
bin/macos/release/interior-collision-probe res/maps/starry_crystal_arena.json artifacts/acceptance/tripo-interior/final-cpu
```

每物体1092条横截面射线首候选统计：仅代理命中船31/骨43/北晶3/南晶4，仅视觉命中0/2/0/1；骨架至少一条被两侧真实骨面包夹的可见孔洞正反向射线及半径0.12m敌弹均通过。主实体正反向阻弹、普通走/滑铲不穿入、真实敌人从地面绕行通过。首候选的四条导航阻断已删。最终正式图以`final-cpu`报告为准。

射线首命中深度偏差不等于最近表面误差：初候选P95船0.129m、骨0.217m、北晶0.066m、南晶0.021m，最大0.884/1.382/0.551/0.413m；细骨轮廓偏移可能使射线跳到后方另一根骨。不能据此宣称所有细孔完全一致或代理逐三角面精确。

实际320×200 GL图在`artifacts/acceptance/tripo-interior/`下。仅短时功能与视觉检查；用户明确取消本轮性能基准，未据此承诺性能。

已知既有局限：Chaser对站在掩体顶面的玩家可能停追。旧31/32同样存在，旧可站采样37/34，新船/骨降至11/7；本次水晶也有少量可站棱面。没有改AI或跳跃规则，也不声称这些掩体不可攀爬。地面追击绕行和Sentry现有压制逻辑保持。
