# Crystal 巨型地图结构

用户澄清需要像巨大骨柱一样的地图结构，本轮取代上一轮四个1.2/1.6m小掩体。复用真实船体、去头腿骨架和矿物水晶，没有调用Tripo，没有新增扣费。旧小模型来源包保留，但31/32/4400/4401实例移除；既有远景、步枪和碎石保持。

## 实际结构与可接近性

- **4500西侧船壳墙**：真实`derelict_ship/parts/wreck-0.obj`旋转侧躺并等比缩放，高12m、沿Z跨度28.26m，放在(-31.3,-2,0)，最终地上最高10m。最低碎角埋入地面。替换28/29/30三根旧西侧斜撑，西侧旧壳21/22降到2.1m作为基座。沿旧路线x=-22可接近金属面：眼高1.6m向西射线在z=-4命中真实船x=-24.54，而旧基座在x=-27.71；z=6时船x=-25.17、旧基座x=-27.35。主面实际位于基座前，部分后方碎边仍嵌在基座后。外伸部分超出地板，但通行边界仍由原可见基座保持。
- **4501东南肋骨墙/拱**：从真实`alien_skeleton/parts/torso-derived.obj`保留所有顶点源X≥3.0的完整三角面，成为一侧巨大肋弧；没有恢复头骨和腿。等比缩放到11m高，在(25,0,18)，跨度约16.95m，实际X范围19.74–30.26、Z范围9.53–26.47。旧18/19外壳只保留0–18°、65–90°两段，中间让出走入肋骨的入口。后方有可见3.5m高轨道基础，内边x30.5/z28.2，加两段回接，均在真实64×64地板内。玩家不会先被骨洞前原位的旧墙挡住，也不会从新增入口直接跌出地板。
- **4502东北晶壁**：真实`mineral_cluster/parts/part-000.obj`等比放大到13m高，放在(20,0,-18)。范围X13.53–26.47、Z-23.94至-12.06。主体已移入原外壳内，能从下层通道走近，不是墙后远景。

没有新谜题、拾取、战斗机制或数值调整。出生/裂隙/敌人/灯光/环境/原41点巡路不变。根据VECTOR功能反馈将导航1移到(-22,0,-6)，移除被晶壁覆盖的41/54及所有关联边；恢复上一轮小水晶删掉的四条边。最终83节点/163连接。地图35个模型实例。

## 离线复现与来源

项目根目录运行（沿用独立工具环境，不改系统Python/游戏运行时依赖）：

```sh
python3 -m venv artifacts/acceptance/tripo-interior/mesh-tools
artifacts/acceptance/tripo-interior/mesh-tools/bin/python -m pip install numpy==2.5.4 scipy==1.18.1
artifacts/acceptance/tripo-interior/mesh-tools/bin/python res/models/tripo/mega/generate.py
artifacts/acceptance/tripo-interior/mesh-tools/bin/python res/models/tripo/mega/build_collision.py
python3 res/models/tripo/mega/build_foundation.py
```

每个`{ship_wall,rib_wall,crystal_wall}/`包含：

- `visual.obj`：真实源三角面、原UV/法线，只作裁取、等比缩放和旋转；仅写实际引用的顶点/UV/法线。
- `provenance.json`：源SHA256、裁切阈值、尺寸、变换、视觉哈希。
- `collision.obj`及`proxy-report.json`：按**最终世界米制尺寸**制作的闭合代理和实测误差；不会放大旧的小掩体代理。

`foundation/`六个OBJ是原有轨道建筑语言的本地基础几何，并非伪称Tripo生成资产；每段视觉和碰撞引用同一网格。它们分别是两段保留外壳和四段东南后退边界。

## 碰撞近似及边界

对源连接片做有界六层局部分段，保留闭合且外法线正确的主要凸壳，采样目标0.20m。若局部采样表面误差超过0.35m或源顶点超代理支持平面0.20m，就用该处真实三角面的**6cm厚闭合薄片**替代，避免整段凸壳跨过明显骨洞。没有无限递归，也没有整个骨架包围盒。

| 结构 | 视觉面 | 代理面 | 闭壳数量 | 实测最大采样近表面偏差 |
| --- | ---: | ---: | ---: | ---: |
| 船壳 | 7336 | 14394 | 1694 | 0.347m |
| 肋骨 | 1354 | 3012 | 364 | 0.339m |
| 晶壁 | 8402 | 27584 | 3442 | 0.343m |

采样是凸壳面中心/边中点到局部源面的距离，不是全表面Hausdorff上界；薄片表面偏移为0.03m。极小或无体积孤片只作为装饰，具体数量见报告。闭壳可局部重叠，最终实际移动/LOS/敌弹与空洞通路由VECTOR功能探针验收。45k左右的代理面是本轮局限：优先防止几米宽空气墙，没有继续盲目加细，也未声称这是最优物理网格。
